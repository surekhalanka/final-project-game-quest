Game Quest — Java Runner

Choose a character, then write Java code that moves it forward and backward, checks for barriers and jumps over them. Your program's output drives the Game Screen: print commands such as @FORWARD 1 or @JUMP 2 and the page animates them.

This page uses Java 8. Avoid newer features such as var, records, text blocks and switch ->. The first run downloads Java into your browser and can take up to a minute.

Game command reference

Print a line that starts with @. It goes to the Game Screen, not the console. Add this method to your Main class and call it, for example show("JUMP 2");


static void show(String command) {
    System.out.println("@" + command);
}


Characters you can use in @CHARACTER name|type (number or word):


1 dinosaur 🦖2 car 🚗3 human 🏃4 animal 🐕cat 🐈horse 🐎rabbit 🐇robot 🤖bike 🚲turtle 🐢




Print thisWhat happens


@PLAYER AlexShows the player name


@CHARACTER Rex|dinosaurCharacter name and type (see list above)


@TRACK 20Builds a track with cells 0 to 20; 20 is the finish 🏁 (5 to 40)


@BARRIER 6 cactusPlaces a barrier on cell 6. Types: cactus, rock, cone, wall, tree, water


@STAR 9Places a star to collect on cell 9


@FORWARD 1Moves forward. Walking into a barrier is flagged as a crash


@BACKWARD 1Moves backward


@JUMP 2Jumps forward 2 cells, over anything in between


@CHECK 6 trueShows your barrier check for cell 6 (true = barrier). A wrong check is flagged


@ENERGY 25 / @MAXENERGY 40Updates the energy bar (full is 30 by default)


@POINTS 50 / @LEVEL 2Updates points and level


@EVENT Strong wind! / @ACTION JumpAdds a message to the event log


@CHALLENGE Desert zoneShows a message in the banner


@COIN heads / @DICE 4Flips the coin or rolls the dice


@RESULT WIN Reached the finishShows the final WIN or LOSE screen
