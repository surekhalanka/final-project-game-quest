Lucky Draw — Java

Run a lucky draw with Java! Give every player a ticket, shuffle the box, then draw winners for three prizes: 1st prize Gold Coin, 2nd prize Silver Coin and 3rd prize ฿3,000 cash. One prize per person. Your program's output drives the stage: print commands such as @DRAW 3 17 and the page animates them.

This page uses Java 8. Avoid newer features such as var, records, text blocks and switch ->. The first run downloads Java into your browser and can take up to a minute.

Game inputs (Scanner)


Enter every answer your program will read, in order, one per line. The program receives these before it starts; it cannot pause for typing. If your program asks for more answers than you typed, you will see NoSuchElementException.


Run your Java program to see results here.



Game command reference

Print a line that starts with @. It goes to the Lucky Draw Stage, not the console. Add this method to your Main class:


static void show(String command) {
    System.out.println("@" + command);
}




Print thisWhat happens


@HOST Dr. LankaShows the host's name on the stage


@TICKET 17|AlexPuts ticket number 17 for Alex into the box (up to 12 tickets, numbers 1 to 999)


@SHUFFLEShakes the box and mixes the tickets


@DRAW 3 17Draws ticket 17 for the 3rd prize (1 = Gold Coin, 2 = Silver Coin, 3 = ฿3,000)


@EVENT And the winner is…Shows a message in the banner and the log


@COIN heads / @DICE 4Flips a coin or rolls a dice


@RESULT DONE Congratulations to all winners!Shows the final screen. The page checks that all 3 prizes went to 3 different people
