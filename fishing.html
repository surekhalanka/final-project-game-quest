Wendy's Fishing Quest — Java

Help Wendy catch fish! Write Java code that creates fish, makes them swim, casts Wendy's rod to the right place and depth, and checks whether a fish is close enough to catch. Your program's output drives the underwater scene: print commands such as @CAST 12 3 and the page animates them.

This page uses Java 8. Avoid newer features such as var, records, text blocks and switch ->. The first run downloads Java into your browser and can take up to a minute.

Game command reference

Print a line that starts with @. It goes to the Underwater Screen, not the console. The water is 0 to 20 wide (x) and 1 to 5 deep (depth). Add this method to your Main class:


static void show(String command) {
    System.out.println("@" + command);
}


Fish types for @FISH:


golden 🐠✨tropical 🐠fish 🐟puffer 🐡shark 🦈octopus 🐙crab 🦀squid 🦑shrimp 🦐




Print thisWhat happens


@PLAYER WendyShows the angler's name on the boat


@FISH 1|Sunny|golden|3|12|50Adds fish id 1, named Sunny, type golden, at depth 3 and x 12, worth 50 points


@SWIM 1 14 or @SWIM 1 14 2Fish 1 swims to x 14 (and optionally to depth 2)


@CAST 12 3Wendy's boat moves to x 12 and the hook drops to depth 3


@CHECK 1 trueShows your check "is fish 1 near the hook?" A wrong check is flagged. Near = same depth and x at most 1 apart


@CATCH 1Fish 1 bites and is pulled up with the hook


@MISS 1Fish 1 escapes and darts away


@REELReels the hook back up; a hooked fish goes into Wendy's bucket


@BAIT 7 / @POINTS 50 / @TURN 3 / @LEVEL 2Updates the counters


@EVENT A shark is near! / @ACTION Cast / @CHALLENGE Golden hourAdds a message to the log or the banner


@COIN heads / @DICE 4Flips the coin or rolls the dice


@RESULT WIN Wendy caught SunnyShows the final WIN or LOSE screen
