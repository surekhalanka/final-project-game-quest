Monkey Jungle Quest — Java

A group of monkeys is hungry! Write Java code that plants trees and fruit, then makes each monkey jump, swing, hang, roll and climb from tree to tree to pluck and eat fruit. Every monkey must eat at least 3 fruits. Your program's output drives the jungle: print commands such as @JUMP 1 2 and the page animates them.

This page uses Java 8. Avoid newer features such as var, records, text blocks and switch ->. The first run downloads Java into your browser and can take up to a minute.

Java code editor

Game inputs (Scanner)


Enter every answer your program will read, in order, one per line. The program receives these before it starts; it cannot pause for typing. If your program asks for more answers than you typed, you will see NoSuchElementException.


Run your Java program to see results here.



Game command reference

Print a line that starts with @. It goes to the Jungle Screen, not the console. The jungle is 0 to 20 wide (x). Add this method to your Main class:


static void show(String command) {
    System.out.println("@" + command);
}


Tree types: tree, palm, banana. Fruit types:


banana 🍌mango 🥭apple 🍎orange 🍊coconut 🥥grapes 🍇pineapple 🍍peach 🍑cherry 🍒




Print thisWhat happens


@PLAYER Jungle KeeperShows your name in the banner


@TREE 1|3|bananaPlants tree id 1 at x 3 (types: tree, palm, banana)


@FRUIT 11|1|banana|10Puts fruit id 11 on tree 1, type banana, worth 10 points (up to 8 per tree)


@MONKEY 1|Momo|1Adds monkey id 1 named Momo, sitting in tree 1


@JUMP 1 2Monkey 1 jumps to tree 2 (trees at most 6 apart)


@SWING 1 4Monkey 1 swings on a vine to tree 4 (at most 12 apart)


@HANG 1Monkey 1 hangs upside down from the branch


@ROLL 1 15Monkey 1 drops to the ground and rolls to x 15


@CLIMB 1 5Monkey 1 climbs tree 5 (must be on the ground next to it)


@CHECK 1 11 trueShows your check "is fruit 11 on monkey 1's tree?" A wrong check is flagged


@PLUCK 1 11Monkey 1 plucks fruit 11 (must be in the same tree)


@EAT 1Monkey 1 eats the fruit it is holding


@POINTS 50 / @TURN 3Updates the counters


@EVENT Momo is full! / @ACTION Swing / @CHALLENGE RainAdds a message to the log or the banner


@COIN heads / @DICE 4Flips the coin or rolls the dice


@RESULT WIN All monkeys are fullShows the final screen. The page checks that every monkey ate at least 3 fruits
